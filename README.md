# Espace collaboratif QGIS plugin

Espace collaboratif QGIS plugin connects QGIS to the collaborative API enabling users to access georeferenced reports and contribute to shared data.

- [Configuration](#configuration)
- [Features](#features)

## Installation

In QGIS, open the **Plugins** menu and select **Manage and Install Plugins...**.
In the official QGIS repositories, search for **Espace collaboratif**, then
select the plugin and click **Install Plugin**.

## Requirements

We recommend using the QGIS 3.44 LTR version.

## Configuration

Check whether you need to configure a proxy. If so, please refer to the
[plugin documentation](https://ignf.github.io/espace-collaboratif-qgis-plugin).

## Features

- Create and manage reports
- Contribute directly to databases
